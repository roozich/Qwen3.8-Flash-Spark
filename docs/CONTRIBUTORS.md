# Contributors

Chronological contributor history for this recipe: who landed which fix, when, and
where it came from. Dates are when the fix landed here; per-release context for each
entry is in [CHANGELOG.md](../CHANGELOG.md). The README keeps only the core
acknowledgements.

- **2026-10-28**: dflash/DFlash2 drafter support (patch 23): **[@roozich](https://github.com/roozich)** ([PR #62](https://github.com/blazux/qwen3.8-Flash-DGX/pull/62)).
- **2026-10-22**: long-context MTP crash report: **[@FinSnow](https://github.com/FinSnow)** ([issue #60](https://github.com/blazux/qwen3.8-Flash-DGX/issues/60)); M-RoPE served-window fix: **[@wtogami](https://github.com/wtogami)** ([vllm#62409](https://github.com/vllm-project/vllm/pull/62409)), adapted as patch 22 to preserve the existing YaRN frequency base and cache rows.
